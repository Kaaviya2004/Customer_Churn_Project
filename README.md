# 🤖 AI Customer Retention Assistant

An AI-powered project to predict Customer Churn and help businesses retain their customers.

### ✨ Features
- 🤖 AI Prediction - Churn Risk + Confidence Score
- 🧠 AI Diagnosis - Why the customer is leaving
- 🎁 Retention Plan - Best Offer to retain the customer
- 📊 Business Impact - Revenue Saving Calculation
- 📄 Report - Complete Customer Report

### 🛠️ Technologies Used
Python, SQL Server, Machine Learning, Streamlit

### ▶️ How to Run
streamlit run app.py
